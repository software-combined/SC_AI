# Router install prompt for your agent

Use the approved staff download at `https://hub.softwarecombined.com/install`.
Choose the native installer for your computer. Windows uses the EXE and
needs no separate Codex CLI, Python install or PATH change.
Give your agent this prompt before starting setup:

> Set up SCG Router through the current approved staff instructions.
> Before starting setup, ask which assistants I use
> (Codex, Claude Code, Claude desktop, or a combination). Keep my existing
> subscriptions as the default and preserve other clients and saved choices.
>
> Use the native installer for my computer and its assistant chooser.
> You can download, open and navigate the supported app within my authorisation.
> Leave credentials, assistant preferences, licence and security decisions to me.
> If Router is already installed, open its permanent SCG Router app.
> Read its status first. Use Update or repair only for a diagnosed fault,
> or Connect another assistant for an explicit addition. Do not create a parallel installation
> or download Codex again merely because command lookup cannot find it.
> Store Codex includes the supported setup tool; Router must discover it.
>
> When setup needs model access, guide me through Sign in with work account
> in the secure setup window when my organisation enables that route.
> If I explicitly choose my own key, I enter it only in that window.
> Never request, read or paste keys, tokens, setup links or configuration
> bodies in chat. Do not create employee keys solely to test setup.
>
> If something fails, diagnose it and complete the supported setup.
> Inspect the redacted status and diagnostics, identify the cause, and make
> the smallest safe correction within my authorised scope. Check that the
> correction worked before retrying the failed step. Resume until the actual
> setup criteria pass; do not stop at a running service or a successful download.
> Do not retry blindly, invent flags, run arbitrary scripts, bypass device
> controls, manually register plugins or change my subscription defaults.
> If a supported correction needs IT access or my decision, explain the
> exact blocker and the next action without claiming setup is complete.
>
> Verify the selected assistants, installed SC plugins and automatic updates
> through SCG Router's Check setup. Follow the current Router management
> skill and retained troubleshooting guide for read-only status diagnostics.
> Use the retained interpreter and tools, without guessing paths or commands.
> Handle missing model access through Set up model access before a test reply.
> Then guide me to a fresh
> assistant chat, a routed model reply and one successful enabled SC tool.
> Preserve plugins I disabled. Report any unverified check separately.
> Closing or restarting an assistant is my explicit choice. Keep this Codex
> session open unless I choose otherwise.

Use the native installer and permanent app on Windows, macOS and Linux.
Keep the existing Router home and channel. An installed assistant does not
need another download. An unclear discovery result needs diagnosis.

Updates are automatic every four hours from the public feed.
No GitHub account or repository checkout is needed.
